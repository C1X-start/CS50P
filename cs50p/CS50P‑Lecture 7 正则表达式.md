## 一、基础字符匹配

### 1. 普通元字符

| 符号       | 含义                            |
| -------- | ----------------------------- |
| `.`      | 匹配**任意单个字符**，换行符 `\n` 除外      |
| `[abc]`  | 字符集，匹配方括号内**任意一个**字符          |
| `[^abc]` | 反字符集，匹配**不在**方括号内的任意一个字符      |
| `\`      | 转义符，让特殊字符恢复本意，例如 `\.` 匹配真实的点号 |

### ⚠️ 重点区分：^ 的两种完全不同作用

这是正则最容易混淆的知识点，两种作用互相独立：

1. **在 `[]` 外面：开头锚点**
    - 作用：匹配字符串的**起始位置**，不占用字符，只做定位
    - 示例：`^hello` 只匹配以 hello 开头的字符串
2. **紧跟在 `[` 后面：取反**
    - 作用：表示“非、不包含”
    - 示例：`[^@]` 匹配除了 @ 以外的任意单个字符

### 2. 预定义字符类

|符号|含义|大写反向|
|---|---|---|
|`\d`|十进制数字 0-9|`\D`：非数字|
|`\w`|字母、数字、下划线|`\W`：非单词字符|
|`\s`|空白字符（空格、制表符等）|`\S`：非空白|

## 二、量词（数量限制）

控制前面一个字符/分组的出现次数。

|符号|含义|
|---|---|
|`*`|前面的内容出现 **0次 或 任意多次**|
|`+`|前面的内容出现 **1次 或 任意多次**（至少1次）|
|`?`|前面的内容出现 **0次 或 1次**（最多1次）|
|`{n}`|精确出现 n 次|
|`{m,n}`|至少 m 次，至多 n 次|

### 💡 等价写法：`..*` 与 `.+`

- `..*` = 1个强制字符 + 0个或多个字符 → 最终效果：**至少1个字符**
- `.+` = 直接定义至少1个字符

二者匹配效果完全一致，`.+` 是更简洁、更推荐的标准写法。

### ⚠️ 易错坑：? 只限制紧邻它前面的单个元素

例如 `@?` 仅表示“这一个位置的@可以有或没有”，**不能限制整个字符串里@的总数量**。 根本原因：`.+` 默认是**贪婪匹配**，会尽可能多地吞掉字符，包括多余的@。

```
# ❌ 错误写法：无法限制只有一个@
r"^.+@?.+\.com$"
# ✅ 正确写法：用反字符集强制恰好一个@
r"^[^@]+@[^@]+\.com$"
```

### 贪婪匹配说明

默认情况下 `*` `+` 都是贪婪模式：尽可能匹配更长的字符串。 例如 `.+@` 在 `a@b@c.com` 中，会一口气匹配到第二个@前面，而不是停在第一个@。

## 三、锚点：限定首尾位置

|符号|含义|
|---|---|
|`^`|匹配字符串**开头**|
|`$`|匹配字符串**结尾**|

加上首尾锚点可以避免“部分匹配”，确保整个字符串完全符合规则，是校验类场景的标准写法。

```
import re

email = input("what's your email?").strip()
if re.search(r"^[^@]+@[^@]+\.com$", email):
    print("valid")
else:
    print("Invalid")
```

## 四、分组与选择

### 1. 或运算：`|`

用括号包裹多个选项，`|` 表示“或”。

```
# 支持多种域名后缀
re.search(r"^[^@]+@[^@]+\.(com|edu|cn|gov)$", email)
```

### 2. 捕获组：`()`

括号内的内容会被编号保存，通过 `.group(n)` 获取，编号从 **1** 开始。

```
import re

name = input("what's your name?")
matches = re.search(r"^(.+), *(.+)$", name)
if matches:
    # 姓和名互换
    name = matches.group(2) + " " + matches.group(1)
print(f"hello,{name}")
```

### 3. 海象运算符精简写法

`:=` 同时完成赋值和布尔判断，合并两行代码。

```
if matches := re.search(r"^(.+), *(.+)$", name):
    name = matches.group(2) + " " + matches.group(1)
```

### 4. 非捕获组：`(?:)`

括号只用来分组，不保存捕获结果，计数时不算入 group 编号。

```
# 前面的域名部分不捕获，只捕获用户名
if matches := re.search(r"^(?:https://(?:www\.)?x\.com/)?(\w+)$", url):
    name = matches.group(1)
```

## 五、标志位（第三个参数）

`re.search(pattern, string, flags)`

- `re.IGNORECASE`：匹配时忽略大小写

```
re.search(r"^[a-zA-Z0-9_\.]+@\w+\.(com|edu|cn|gov)$", email, re.IGNORECASE)
```

## 六、替换：re.sub()

```
re.sub(要替换的模式, 替换成什么, 原字符串)
```

示例：

```
import re
url = input("what's your x name?").strip()
name = re.sub(r"https://www\.x\.com/", "", url)
print(f"hello,{name}")
```

## 七、常见易错点汇总

1. **^ 的含义看位置**：在 `[]` 里是取反，在外面是开头锚点，二者完全无关。
2. **`.` 不匹配换行**：默认情况下点号不能匹配换行符。
3. **特殊字符要转义**：匹配真实的 `.` `*` `?` 等符号，前面要加 `\` 转义；正则字符串推荐加 `r` 前缀，避免转义符被Python提前解析。
4. **`?` 只管紧邻的前面一个元素**，不能全局限制数量；限制全局数量要用反字符集，比如 `[^@]+`。
5. **默认贪婪匹配**：`+` `*` 会尽可能多匹配字符，容易导致匹配范围超出预期。
6. **捕获组从1开始计数**：`group(0)` 是匹配到的完整字符串，`group(1)` 才是第一个括号的内容。
7. 判断字符串是否为空，直接用 `if 字符串:` 即可，空字符串本身等价于 False。
