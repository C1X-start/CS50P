## 一、字符串与布尔判断
### 1. 空字符串简洁判空
- 规则：空字符串在条件判断中会隐式等价于 `False`
- 用法：直接用 `if not 字符串` 判断输入是否为空，无需写 `== ""`
- 典型场景：校验用户输入是否为空
```python
name = input("请输入姓名：").strip()
if not name:
    print("输入不能为空")
````

## 二、数值格式化输出

### 2. f-string 控制小数位数

- 语法：`f"{变量:.nf}"`，n 为要保留的小数位数
- 特点：自动四舍五入，仅作用于展示输出，不改变变量本身的数值
- 典型场景：计算平均值、金额等需要固定精度的输出

```
avg = sum(nums) / len(nums)
print(f"平均值：{avg:.2f}")  # 保留2位小数
```

## 三、列表常用操作

### 3. append() 向列表添加元素

- 语法：`列表.append(元素)`
- 特点：在列表**末尾**追加元素，原地修改列表，返回值为 None
- ⚠️ 注意：不要写成 `nums = nums.append(x)`，会把列表变量覆盖成 None
- 典型场景：循环收集多个输入数据

```
nums = []
for i in range(5):
    num = int(input(f"请输入第{i+1}个整数："))
    nums.append(num)
```

## 四、字典常用操作

### 4. in 关键字判断键是否存在

- 语法：`键 in 字典`
- 作用：安全判断字典中是否包含指定键，避免键不存在时报错
- 典型场景：字典查询前的校验

```
scores = {"Alice": 85, "Bob": 72}
name = input("请输入学生姓名：")
if name in scores:
    print(f"{name} 的成绩是：{scores[name]}")
else:
    print("未找到该学生")
```

### 5. items() 同时遍历键和值

- 语法：`for 键变量, 值变量 in 字典.items():`
- 优势：无需先遍历键再通过键取值，代码更简洁，执行效率更高
- 典型场景：遍历字典同时输出键和值

```
scores = {"Alice": 85, "Bob": 72}
for student, score in scores.items():
    print(f"{student}: {score}")
```
