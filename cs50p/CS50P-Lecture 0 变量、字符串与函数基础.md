## 📖核心知识点

### 一、输入输出基础

#### 1. input() 输入函数

- `input()` 内置提示文本输出功能，括号内可直接写提示字符串，无需额外搭配 `print`
- 输入结果默认是**字符串类型**，做数值运算必须先用 `int()` / `float()` 转换类型

#### 2. print() 输出控制

- 位置参数：要打印的内容，如 `"123"`、变量名
- 命名参数（关键字参数）：

|参数|作用|默认值|
|---|---|---|
|`sep`|多个输出内容之间的分隔符|空格|
|`end`|打印结束后末尾追加的字符|换行符 `\n`|

- 内容拼接区别：
    - `+` 拼接字符串：**不会自动添加空格**
    - `,` 分隔多个参数：**自动添加空格**

```
name = "Tom"
print("Hi", name)   # 输出 Hi Tom（自动带空格）
print("Hi" + name)  # 输出 HiTom（无空格）
print("a","b","c", sep="???")  # 输出 a???b???c
```

#### 3. 字符串内输出引号的两种方案

1. **单双引号嵌套（推荐）**：外层与内层使用不同引号，无需转义，可读性更好

```
print('hello, "friend"')
print("hello, 'friend'")
```

2. **转义字符 `\`**：在需要打印的引号前加反斜杠进行转义

```
print("hello , \"friend\"")
```

#### 4. f-string 格式化字符串

Python 3.6+ 推荐写法，在字符串前加 `f`，`{}` 内直接写入变量或表达式，运行时自动替换为实际值。

```
name = "Alice"
print(f"hello, {name}")
```



### 二、字符串格式化与处理

用于规范用户输入，去除多余空格、统一大小写等。

|方法|作用|
|---|---|
|`.strip()`|去除字符串首尾多余的空格|
|`.capitalize()`|仅整个字符串首字母大写，其余字母小写|
|`.title()`|每个单词的首字母都大写|

#### 函数链式调用

多个方法可以按从左到右的顺序连续调用，简化代码结构。

```
# 分开写法
name = input("请输入你的名字")
name = name.strip()
name = name.title()

# 链式调用（功能完全等价）
name = input("请输入你的名字").strip().title()
```

#### split() 拆分字符串

按指定分隔符切割字符串，可同时赋值给多个变量。

```
# 按空格拆分名和姓
first, last = name.split(" ")
```

⚠️ 严格匹配分隔符：输入包含多个空格时会报错，仅适用于单空格分隔的场景。

### 三、数值类型与运算

#### 1. 整数 int

- Python 中整数大小没有上限，不会出现溢出问题
- 美式千分位格式化输出：

```
z = 1234567
print(f"{z:,}")  # 输出 1,234,567
```

#### 2. 浮点数 float 精度陷阱 ⚠️

计算机以**二进制**存储小数，绝大多数十进制小数（如 `0.1`、`0.23`）无法被二进制精确表示，只能存储一个近似值，运算后微小误差会显现出来。

```
# 示例：1.23 + 1.2 数学结果为 2.43
x = 1.23
y = 1.2
print(x + y)  # 输出 2.4299999999999997
```

这是几乎所有编程语言的共性，并不是 Python 的 bug。

#### 3. round() 舍入函数 ⚠️

官方语法：`round(number[, ndigits])`

- `number`：待舍入的数值
- `ndigits`：可选参数，保留的小数位数；不填写则默认保留为整数
- ❗ **不是传统“四舍五入”**，采用**银行家舍入（四舍六入五成双）**：
    - 小数部分恰好为 `.5` 时，舍入到最近的偶数
    - 叠加浮点数精度误差后，结果可能与直觉不符

```
print(round(2.5))   # 2（向偶数靠拢）
print(round(3.5))   # 4（向偶数靠拢）
print(round(1.2 + 1.3))  # 2（受浮点数精度影响，内部值略小于2.5）
```

#### 4. 保留小数位的推荐方案

日常展示结果优先使用 f-string 限定小数位，比 `round()` 结果更符合常规预期：

```
z = x + y
print(f"{z:.2f}")  # 保留2位小数
```

### 四、函数基础

#### 1. 函数定义与默认参数

语法：`def 函数名(参数=默认值):`

- 不传入参数时，自动使用预设的默认值
- 函数必须**先定义，后调用**

```
def hello(to="world"):
    print("hello,", to)

hello()          # 输出 hello, world
hello("Alice")   # 输出 hello, Alice
```

#### 2. main() 函数代码规范

为解决“函数必须先定义再调用”的顺序问题，Python 约定俗成将主逻辑写入 `main()` 函数，在文件末尾统一调用，保证所有函数都已完成定义。

```
def hello(to="world"):
    print("hello,", to)

def main():
    hello()
    hello("Alice")

main()
```

#### 3. return 返回值

函数通过 `return` 将计算结果返回，调用处可以接收结果继续参与运算。

```
# 示例：求一个数的幂
def power(base, exp):
    return base ** exp

result = power(2, 3)
print(result)  # 8
```

pow函数也可以求幂

```python
print(pow(2,3))  #8 左侧参数，右侧幂
```

## ❗易错点 & 踩坑记录

1. ⚠️ `input()` 返回值默认是字符串，做加减乘除必须先转换为 `int()` / `float()`
2. ⚠️ 用 `+` 拼接字符串不会自动补空格，容易出现单词连在一起的问题
3. ⚠️ `round()` 不是小学数学的四舍五入，`.5` 会向偶数方向舍入
4. ⚠️ 浮点数直接判断相等 `0.1 + 0.2 == 0.3` 结果为 `False`
5. ⚠️ `split(" ")` 严格匹配单个空格，多空格输入会直接报错
6. ⚠️ 函数调用必须写在定义之后，推荐统一用 `main()` 函数组织代码

```
y = float(input("y的值为"))
print(f"{x + y:.2f}")

# 千分位格式化
num = 1234567
print(f"{num:,}")

# 标准函数结构
def main():
    # 主逻辑写在这里
    pass

if __name__ == "__main__":
    main()
```
